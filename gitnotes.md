Essential Git Commands



1. git init: Creates a new, empty local Git repository.

   Example: git init



2. git clone: Downloads a repository from GitHub to your computer.

   Example: git clone https://github.com/user/repo.git



3. git status: Shows the current state of your files (staged, unstaged, untracked).

   Example: git status



4. git add: Stages files to be included in your next save.

   Example: git add .



5. git commit: Permanently saves the staged changes with a description.

   Example: git commit -m "add notes"



6. git log: Displays the history of all past commits.

   Example: git log



7. git branch: Lists your local branches or creates a new one.

   Example: git branch new-feature



8. git checkout: Switches your working directory to a different branch.

   Example: git checkout main



9. git push: Uploads your saved local commits to GitHub.

   Example: git push origin main



10. git pull: Downloads the latest changes from GitHub and merges them locally.

    Example: git pull origin main
